# Random Password Generator

## Автор
Саттаров Ильнур

## Описание
Графическое приложение на Python для генерации случайных паролей с настраиваемыми параметрами. Приложение позволяет выбирать длину пароля, типы используемых символов (цифры, буквы, спецсимволы), а также сохраняет историю сгенерированных паролей в формате JSON.

## Возможности
- Настройка длины пароля (от 4 до 64 символов) через ползунок.
- Выбор типов символов: цифры, строчные/прописные буквы, специальные символы.
- Генерация пароля с использованием библиотеки `random`.
- Отображение сгенерированного пароля.
- Копирование пароля в буфер обмена одним кликом.
- Сохранение истории паролей с датой и временем генерации.
- Загрузка истории при запуске приложения из файла `password_history.json`.
- Возможность очистки истории.

## Требования
- Python 3.6+
- Библиотека `tkinter` (обычно входит в стандартную установку Python)
